填写说明

输入金额：方向设为「税后倒推」时填目标净得，设为「税前正算」时填税前金额；劳务税前正算填不含增值税收入，工资正算填本期税前工资。

手动覆写：详细设置里，增值税、城建税、教育附加、地方教育附加和个税的「手动税额」留空为自动；填 0 表示强制使用零；填其他金额以手填金额参与正反算。结果导出包含全部输入参数，便于复核。

数据保护：建议先用工号或内部编号测试。请勿把含个人身份信息的计算结果文件上传到公开 GitHub 仓库。
