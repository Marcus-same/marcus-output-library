使用时重点核对

  • 同一自然人在同一天向同一付款单位提供多笔应税服务，应按规定汇总核对起征点；不可通过拆分付款规避计税。
  • “个人已缴增值税”不意味着税费为零，只表示企业无须重复代扣；公司转账额与个人最终净得可能不同。
  • 北京无优惠默认全部征收教育费附加与地方教育附加；如手动启用任何优惠选项，须重新核验适用条件。
  • 本工具计算的是本次支付预扣税，年度综合所得汇算可能多退少补；不是个人全年最终个税。
